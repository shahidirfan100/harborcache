# Source and licensing

HarborCache is a modified GPLv3 fork of Redis Object Cache 3.0.0, supplied in `redis-cache.3.0.0.zip`. The upstream project is https://github.com/rhubarbgroup/redis-cache, by Till Krüss and contributors. Its license is retained in `LICENSE.md`. Third-party notices remain with the bundled libraries.

Original additions: HarborCache branding, dashboard, configuration bridge, advanced cache subclass, namespace invalidation, typed value codec, split-alloptions implementation, protected administration forms and guarded lifecycle controls.

Public Object Cache Pro documentation informed early feature comparisons and roadmap discussions. Those references do not identify HarborCache's source base or imply affiliation, endorsement, interface compatibility or feature parity. The historical comparison reports remain available as research records. HarborCache's source base is the free GPL Redis Object Cache version identified above.

HarborCache was developed for the author's websites and their administration needs. Its additions do not make the inherited engine independently authored. A future independent engine is a separate project proposal; existing source attribution and license notices remain applicable to retained code. General fixes should be assessed for upstream contribution separately from HarborCache-specific interface and workflow changes.

The HarborCache name is a working product identity. Trademark availability, plugin-directory slug availability, and directory acceptance have not been established.
