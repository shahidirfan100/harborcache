# Source and licensing

HarborCache is a modified GPLv3 derivative of a GPL-licensed Redis object-cache engine. The original project, its authors and the modification notice are recorded in `LICENSE.md`; that attribution is retained because the license requires it. All inherited code remains under GPLv3, and the license text is reproduced in full in `LICENSE.md`.

The drop-in and plugin carry their own headers and the GPL license URI. Third-party notices remain with the bundled libraries.

Original additions: HarborCache branding, dashboard, configuration bridge, advanced cache subclass, namespace invalidation, typed value codec, split-alloptions implementation, protected administration forms and guarded lifecycle controls.

HarborCache was developed for the author's websites and their administration needs. Its additions do not make the inherited engine independently authored. A future independent engine is a separate project proposal; existing source attribution and license notices remain applicable to retained code.

The HarborCache name is a working product identity. Trademark availability, plugin-directory slug availability and directory acceptance have not been established.
