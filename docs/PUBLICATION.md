# GitHub publication

HarborCache 1.1.3 is built from the current product source, CRC-extracted and compared with the local installed plugin and repository. The installable ZIP excludes CI/tests, media, local WordPress configuration, credentials and proprietary reference sources. Nine current screenshots show a local fixture with demonstration chart samples; they are not production speed evidence.

See VALIDATION-1.1.3.md, COMPARISON-1.1.3.md, validation-1.1.3.json and publication-checks.json for measurements, exact package checksum and parity results. The latest installable ZIP is in dist; media is separately packaged in the GitHub release. Older installable binaries and screenshots have been replaced in the current checkout. Historical Git history/releases remain available for reproducible baseline comparison and rollback.
