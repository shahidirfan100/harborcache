# HarborCache 1.1.5

This maintenance release restores the complete plugin identity, `HarborCache – Object Cache with Redis`, in the WordPress plugin header and readme. The settings page now uses the same full title, and its descriptor explains the product purpose. The compact HarborCache label remains in the settings navigation and dashboard widget.

The release refreshes all nine dashboard and mobile screenshots. Captures omit the version footer and runtime version field so the images remain reusable between releases. Their chart history is seeded test data from a local WordPress fixture, not production performance evidence.

No cache engine, connection option, stored configuration, Redis key namespace, or drop-in behavior changes in this release. Existing sites can upload the version 1.1.5 package over the installed plugin. The owned drop-in update mechanism remains available if WordPress reports it as outdated.
