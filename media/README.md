# HarborCache media

HarborCache interface screenshots were captured on 2026-10-14 from a running local WordPress test site using the 1.2.0 build. Screenshots 1–6 show Overview, Analytics, Connection, Groups, Tools and Diagnostics; screenshot 7 shows the dashboard widget. Mobile screenshots show Connection and the widget at 375px. The settings-page version footer is hidden in the captures, and no plugin version is visible in the images. Chart history contains local demonstration samples. These images are not production measurements or customer data. Capture details are in screenshots.json.

Original logos, icons, favicon, banners and social artwork use teal #0b615e and ink #172b32. Media is separate from the installable plugin package. Original HarborCache media: GPL-2.0-or-later, Shahid Irfan.
